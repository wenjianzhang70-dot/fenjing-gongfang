故事结构模板

产品展示

模板：开箱全景 → 产品细节特写 → 使用过程跟拍 → 使用前后对比 → 结尾定格产品与一句卖点旁白。

适用说明：适合带货、种草、电商产品视频，重点在细节特写和前后对比。

剧情短片

模板：日常开场 → 出现意外或误会 → 主角做出选择 → 反转揭示真相 → 一句收束旁白定格。

适用说明：适合 1–3 分钟剧情类短视频，反转放在倒数第二镜效果最好。

知识讲解

模板：一个生活问题开场 → 手绘/图示拆解原理 → 举一个日常例子 → 常见误区提醒 → 一句话总结。

适用说明：适合科普、教学干货，配手绘知识卡风格效果最好。

口播

模板：痛点一句话开场 → 讲清 3 个要点（每点一个例子）→ 常见错误提醒 → 结尾号召互动。

适用说明：适合口播、干货分享类账号，结构固定，换主题就能复用。

风景混剪

模板：航拍大景开场 → 四季/昼夜切换 → 人物点缀其中 → 空镜转场 → 日落或星空收尾。

适用说明：适合旅行、城市宣传类混剪，音乐节奏比旁白更重要。

单镜模板

开场

模板：全景固定机位或航拍俯瞰，交代环境与时间，淡入。

适用说明：任何长视频的第一镜，先立住“这是在哪、什么时候”。

转场

模板：用一个相似形状或动作衔接前后两镜，例如推门 → 下一场景的门打开。

适用说明：两镜之间不想硬切时用，动作衔接比纯叠化更顺。

特写

模板：特写镜头，缓慢推近，突出一个关键细节或人物表情变化。

适用说明：转折、高潮、情绪点都适合给一个特写，信息密度最高的一镜。

全景

模板：全景或远景，固定机位或缓慢横移，展示空间关系与人物位置。

适用说明：段落切换、场景交代时用，让观众重新定位。

结尾

模板：回到开场画面做呼应，定格一帧，淡出，加一句收束旁白。

适用说明：收束全片用，呼应开场会让片子显得完整。

风格预设

手绘知识卡风

模板：米色纸面底色，黑色手绘线条，荧光黄点缀重点，画面干净、字迹清晰。

适用说明：知识讲解、科普类首选，重点信息用荧光黄标出来。

像素风

模板：颗粒感像素画面，色彩鲜明，复古游戏感，动作简单夸张。

适用说明：搞笑、游戏、怀旧题材，动作写简单点更稳。

电影感

模板：电影级光影，浅景深，胶片质感，16:9 宽画幅，运镜克制缓慢。

适用说明：剧情、品牌广告类首选，运镜宁慢勿快。
